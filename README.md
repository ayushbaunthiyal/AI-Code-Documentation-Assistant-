# AI Code Documentation Assistant

A **Production-Ready** Conversational AI system that "reverse engineers" codebases using **Agentic RAG**, **Memgraph (Graph Database)**, and **Multi-Agent Systems (LangGraph)**.

## 🚀 Quick Setup

**Prerequisites**: Docker Desktop installed.

1.  **Clone the repository**:
    ```bash
    git clone <this-repo-url>
    cd AI-Code-Documentation-Assistant
    ```

2.  **Configuration**:
    The project uses **Strict Configuration Validation**.
    Copy the example env file:
    ```bash
    cp .env.example .env
    ```
    *Edit `.env` and set your `OPENAI_API_KEY`.*

3.  **Run with Docker Compose**:
    ```bash
    docker-compose up --build
    ```

4.  **Access the UI**:
    Open [http://localhost:8503](http://localhost:8503).

5.  **Access Memgraph Lab**:
    Open [http://localhost:3000](http://localhost:3000) (User/Pass: `memgraph`/`memgraph`).

## 🏗 Enterprise Architecture

The system generates a **Knowledge Graph** of your code (AST Analysis) and allows an AI Agent to navigate it.

### 1. Client Service (`client/`)
*   **Tech**: Streamlit, LangGraph, LangChain.
*   **Role**: The "Brain". Enforces **Single-Repo Context**.
*   **Agent Pipeline**:
    *   🕵️‍♂️ **Discoverer**: Identifies tech stack & entry points.
    *   🗺️ **Mapper**: Queries Memgraph for class/function dependencies.
    *   📝 **Summarizer**: Synthesizes technical answers.

### 2. MCP Server (`mcp_server/`)
Refactored into a **Clean Architecture** for maintainability:

```
mcp_server/
├── app/
│   ├── core/         # Configuration (Pydantic) & Structured Logging
│   ├── services/     # Business Logic
│   │   ├── parser_service.py  # Tree-sitter AST parsing
│   │   └── graph_service.py   # Memgraph Interactions
├── main.py           # FastMCP Entrypoint
└── pyproject.toml    # Dependency Management (uv)
```

### 3. Database (`memgraph`)
*   **Tech**: Memgraph Platform (Docker).
*   **Role**: Stores the Semantic Code Graph.
    *   **Nodes**: `File`, `Class`, `Function`.
    *   **Edges**: `BaseClass -> INHERITS -> SubClass`, `Function -> CALLS -> Function`.
